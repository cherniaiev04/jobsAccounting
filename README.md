# Jobs accounting (IN PROGRESS)

## Project Overview
This is a web applicagion designed for a renovation company that has an internal ERP system and many contractors for renovation. The service needs to connect ERP system with contractors to update data (upload photos, status updates, etc). 

## Now I am working on 
- Implement a design
- Implement Prisma for DB
- Implement long term JWT Token

## Features

- Update Status of job
- Upload photos as a result of job
- Update information from ERP System

## Technologies Used

The project utilizes the following technologies:

- **Backend**: Express JS, JavaScript, Prisma, JWT;
- **Frontend**: Vite, Vue, Axios, Tailwind CSS;
- **Database**: PostgreSQL, Redis
